# Event Ticket Booking System

A web-based event ticket booking system built with PHP and MySQL database.

## 🚀 Features
- Browse upcoming events and ticket details
- Interactive event card UI components
- Database architecture supporting 1-to-many relationships (Events -> Bookings)
- Unique booking code generation for user confirmation

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** PHP
- **Database:** MySQL (XAMPP / SSMS)

## 💻 How to Run Locally
1. Clone or download this repository.
2. Place the project folder inside your XAMPP `htdocs` directory.
3. Import the `.sql` database file into **phpMyAdmin**.
4. Configure database connectivity in your PHP connection file (`db.php` / `config.php`).
5. Open your browser and navigate to `http://localhost/event-ticket-booking`.
